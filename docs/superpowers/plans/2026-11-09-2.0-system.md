# Clone'n'Speak 2.0 — подплан D: системные страницы (Task 8 мастер-плана)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Страницы СИСТЕМЫ работают: **Jobs** (`jobs`) — история каждой долгой задачи с логом, остановкой и повтором, переживает перезапуск; **API & Bridge** (`api`) — локальный REST на 127.0.0.1 с ключом и удалённый доступ через `cloudflared` с одобрением устройств; **Plugins** (`plugins`) — свои плагины отдельным процессом; **Data & Privacy** (`privacy`) — что где лежит и что уходит в сеть; **Offline mode** в Настройках и согласие на сеть при первом использовании. Всё сетевое и всё сторонне-кодовое выключено по умолчанию.

**Architecture:** Один менеджер задач `OVJobs` в приложении (ObjC, Foundation-only ядро `OVJobStore` + раннеры). Всё, что живёт долго — озвучка, пакеты, конвертация, обучение, разделение, установка, плагины, задачи из API — идёт через него (подплан C и B только регистрируют свои виды). HTTP-сервер — **отдельный маленький Python-процесс `cns_api.py`** (stdlib, основное окружение), который разговаривает с приложением JSON-строками по stdin/stdout, как `worker.py`. Сетевая политика — один шлюз `OVNetwork` (ObjC) + `cns_net.py` (Python, для процессов).

**Tech Stack:** Objective-C/AppKit, Python 3 stdlib (`http.server`, `hmac`, `hashlib`, `socket`), Security.framework (Keychain), CommonCrypto (SHA-256), CoreImage (QR), `sandbox-exec`, `cloudflared` (скачивается по кнопке). Дизайн: `OVDesign`/`OVUI` и помощники задачи 5.0 подплана A (`OVPageHeader`, `OVPageScroll`, `OVFieldBlock`, `OVSwitch`, `OVPopup`, `OVTableRowView`, `OVColumns`, `OVColorAlpha`).

**Spec:** `docs/superpowers/specs/2026-11-09-clonenspeak-2.0-design.md` (СИСТЕМА; «Решения основной сессии»: API, Bridge, Плагины, Сеть). Референсы Applio (только вид и тексты, не паритет): `applio-refs/jobs.png`, `en_US.json` (Job history, Bridge Mode, privacy).

## Global Constraints

Всё из «Global Constraints» мастер-плана и подплана A (цвета только `OVColor`/`OVColorAlpha`, без эмодзи, размеры отступов, строки `L(@"…")`, только фрагменты `Resources/ru.lproj/fragments/system-<имя>.strings`; `tools/strings.py merge` — только в 8.10) плюс:

- **Безопасность (поверхность атаки — API и Bridge):** слушаем только `127.0.0.1` (никогда `0.0.0.0`/`::`); ключ обязателен на каждом запросе, сравнение `hmac.compare_digest`; ключ в Keychain (`kSecAttrAccessibleWhenUnlockedThisDeviceOnly`), в `UserDefaults`, логах, job-файлах, argv, env — никогда (серверу уходит только SHA-256 ключа, через stdin); лимиты размеров до чтения тела; CORS выключен (любой `Origin` → 403, нет `Access-Control-*`); `Host` проверяется (защита от DNS rebinding); ни один параметр запроса не становится путём: клиент называет только `jobId`/`voiceId`/`uploadId`/`model` с жёстким форматом, сервер ищет их в собственных таблицах; вывод пишется только в папки приложения; ограничение частоты и числа соединений; Bridge — отдельный слушатель, у каждого устройства свой токен после одобрения на Mac; плагины никогда не получают ключ API, токен HF и вообще окружение приложения.
- Всё, что идёт в сеть, проходит `OVNetwork` (ObjC) или `cns_net.require_online` (Python). Тест-сторож `test_network_allowlist` падает на новом сетевом коде вне белого списка.
- В `job.json` и логах секреты не хранятся: ключи запроса `token|key|password|secret|authorization|hf_token` заменяются на `***` до записи.
- Долгая задача не зависит от страницы: менеджер — синглтон; переход между страницами ничего не останавливает. Закрытие последнего окна при активных задачах или включённом API не завершает приложение (`applicationShouldTerminateAfterLastWindowClosed` → `NO` в этих случаях, значок в Dock остаётся, `applicationShouldHandleReopen` открывает окно); ⌘Q при активных задачах спрашивает «Остановить и выйти / Отмена».
- Python в `tests/` — только stdlib и то, что есть в CI (`numpy`, `scipy`); ObjC-логика без AppKit тестируется отдельным исполняемым файлом (`tests/objc/*.m`, собирается и запускается из `tests/test_objc.py`, пропускается без `clang`). `build.sh --test` и CI это уже запускают (`unittest discover`).
- Новые `Sources/*.py` копируются в рантайм все (подплан B обобщил копирование `worker.py`; если нет — 8.1 Step 1 добавляет `Sources/*.py` в `build.sh` и `OVWorker installScript`).
- Коммит на задачу, в `release/2.0`, английское сообщение + трейлер соавтора как в остальных коммитах сессии.

## Выбор: где живёт HTTP-сервер

**Решение: отдельный процесс `cns_api.py` (Python stdlib `http.server`) в основном окружении, связь с приложением — JSON-строки по stdin/stdout.** Воркер отпадает: он обслуживает один запрос за раз и держит модель; HTTP-слушатель внутри него блокировался бы на каждой озвучке и умирал вместе с выгрузкой по простою. Network.framework в ObjC даёт хорошую изоляцию, но разбор HTTP, лимиты, multipart и т. п. пришлось бы писать вручную на языке без быстрых тестов — это и есть самое рискованное место; в Python это ~400 строк поверх проверенного разбора запросов stdlib, и весь сервер (авторизация, лимиты, схема, Bridge-пейринг) тестируется `unittest` с настоящими сокетами и подставным бэкендом прямо в CI на 3.11 без зависимостей. Сервер не исполняет работу сам, а только валидирует и передаёт задачу приложению (`OVJobs`), поэтому очередь, память и «одна тяжёлая задача за раз» остаются в одном месте, а API-задачи видны на странице Jobs. Процесс весит ~15 МБ без модулей, не держит PyTorch и завершается сам при EOF на stdin (приложение умерло — сервера нет, сирот не остаётся). Цена — второй процесс и протокол, но он тот же формат, что у `worker.py` и pro-движков (подплан C).

Протокол (`cns_api.py` ⇄ `OVAPI`), по строке JSON на сообщение:
```
app → server: {"op":"config","port":18777,"key_sha256":"<hex>","limits":{…},"voices":[…],"models":{…},"devices":[…]}
              {"op":"catalog",…} {"op":"job",…snapshot} {"op":"submitted"/"rejected","reqId",…}
              {"op":"pair_decision","pairId","approve"} {"op":"bridge","host":"x.trycloudflare.com"|null} {"op":"revoke","deviceId"} {"op":"quit"}
server → app: {"op":"listening","port":N,"bridgePort":M|null} {"op":"error","code","msg"}
              {"op":"submit","reqId","kind","params","origin":"api"|"bridge:<deviceId>"} {"op":"stop","jobId"}
              {"op":"pair_request","pairId","name","code"} {"op":"device_added","id","name","token_sha256"} {"op":"device_seen","id"}
```

```objc
// OVJobs.h
extern NSNotificationName const OVJobsDidChangeNotification;   // object: OVJob или nil; смена состояния — сразу, progress/status — не чаще 4 раз/с
typedef NS_ENUM(NSInteger, OVJobState) { OVJobQueued, OVJobRunning, OVJobSucceeded, OVJobFailed, OVJobStopped, OVJobInterrupted };
typedef NS_ENUM(NSInteger, OVJobLane) {
    OVJobLaneCompute,   // OVWorker и pro-движки: одна задача за раз (память), FIFO
    OVJobLaneNetwork    // загрузки/установки файлов: одна за раз, параллельно с compute
};
// виды (kind): synth batch clone convert train separate install download plugin  (строки, расширяемо)
extern NSString *const OVJobKindSynth, *const OVJobKindBatch, *const OVJobKindConvert, *const OVJobKindTrain,
                       *const OVJobKindSeparate, *const OVJobKindInstall, *const OVJobKindDownload, *const OVJobKindPlugin;
// origin: @"app" | @"api" | @"bridge:<deviceId>" | @"plugin:<id>"

@interface OVJob : NSObject
@property (readonly, copy) NSString *identifier;     // yyyyMMdd-HHmmss-<6hex>, сортируемый; формат фиксирован (его проверяет API)
@property (readonly, copy) NSString *kind, *title, *origin;
@property (readonly) OVJobState state;  @property (readonly) OVJobLane lane;
@property (readonly, copy) NSDate *created;  @property (readonly, nullable, copy) NSDate *started, *finished;
@property (readonly) double progress;                 // 0…1, <0 — неопределённый
@property (readonly, copy) NSString *status;          // последняя строка статуса
@property (readonly, nullable, copy) NSString *error; // с действием: «что сделать»
@property (readonly, copy) NSDictionary *request;     // JSON-безопасный, секреты заменены на ***
@property (readonly, nullable, copy) NSDictionary *result;  // JSON-безопасный результат (path, seconds, …); в памяти и в job.json
@property (readonly, copy) NSArray<NSString *> *outputs;   // абсолютные пути готовых файлов
@property (readonly, nullable, copy) NSString *retryOf;
@property (readonly, copy) NSString *folder, *logPath, *workDirectory;  // jobs/<id>/, log.txt, work/
@property (readonly) BOOL active, retryable;          // active = Queued|Running
- (NSString *)logText;                                // хвост лога, ≤ 256 КБ для показа
@end

@protocol OVJobRunner <NSObject>                      // экземпляр на один запуск
- (void)start:(OVJob *)job context:(OVJobContext *)ctx;   // обязан завершиться ровно одним succeed/fail
- (void)stop:(OVJob *)job;                                // асинхронно; после него раннер зовёт fail/succeed, менеджер сам решит Stopped
@end
@interface OVJobContext : NSObject                    // потокобезопасен
@property (readonly) BOOL stopRequested;
@property (readonly, copy) NSString *workDirectory;   // временные файлы только сюда: удаляется целиком при любом исходе кроме Succeeded-после-commit
- (void)setStatus:(NSString *)s;  - (void)setProgress:(double)p;  - (void)log:(NSString *)line;
- (void)registerPartialPath:(NSString *)path;         // файл, который удалить при Stopped/Failed; принимается только внутри Support/Outputs/NSTemporaryDirectory
- (void)succeedWithResult:(nullable NSDictionary *)result outputs:(NSArray<NSString *> *)finalPaths;
- (void)failWithError:(NSString *)message;
@end

typedef id<OVJobRunner> _Nonnull (^OVJobRunnerFactory)(OVJob *job);
@interface OVJobs : NSObject
+ (instancetype)shared;                               // корень <support>/jobs
+ (instancetype)jobsWithRoot:(NSString *)root;        // для тестов
@property (readonly) NSArray<OVJob *> *all;           // новые сверху
@property (readonly) NSUInteger activeCount;
/// Регистрация вида. onSuccess — общий постпроцесс (например запись в историю), вызывается на main для любого origin.
- (void)registerKind:(NSString *)kind lane:(OVJobLane)lane retryable:(BOOL)retryable
               title:(NSString *(^)(NSDictionary *request))title
             factory:(OVJobRunnerFactory)factory
           onSuccess:(nullable void (^)(OVJob *job))onSuccess;
/// nil + error, если вид не зарегистрирован или очередь полна (origin api/bridge: ≤ 8 активных).
- (nullable OVJob *)submitKind:(NSString *)kind request:(NSDictionary *)request origin:(NSString *)origin
                       onFinish:(nullable void (^)(OVJob *job))onFinish error:(NSString *_Nullable *_Nullable)error;
- (void)stop:(OVJob *)job;                            // Queued → Stopped сразу; Running → runner stop
- (nullable OVJob *)retry:(OVJob *)job;               // тот же kind+request, новый id, retryOf = старый; nil если !retryable
- (void)remove:(OVJob *)job;  - (void)clearFinished;  // только завершённые; удаляют папку задачи
- (nullable OVJob *)jobWithId:(NSString *)identifier;
- (void)stopAllAndWait:(NSTimeInterval)timeout;       // для выхода: всё Stopped, work/ удалены
@end

// Стандартные раннеры (их берут B и C)
OVJobRunnerFactory OVWorkerRunnerFactory(void);       // request[@"cmd"] → [OVWorker request]; ждёт, пока OVWorker.busy (прямые вызовы страниц) освободится; stop → [OVWorker stop]
@interface OVProcessSpec : NSObject
@property (copy) NSString *executable; @property (copy) NSArray<NSString *> *arguments;
@property (copy) NSDictionary<NSString *, NSString *> *environment;   // ровно это, без наследования
@property (copy, nullable) NSString *currentDirectory; @property (copy, nullable) NSData *stdinData;
@property (copy, nullable) void (^beforeStart)(void (^proceed)(BOOL ok, NSString *_Nullable error));  // выгрузка OmniVoice, проверка памяти
@end
OVJobRunnerFactory OVProcessRunnerFactory(OVProcessSpec *(^specFor)(OVJob *job));
// Процесс запускается в своей группе; stdout — JSON-строки как у worker.py:
//   {"event":"status","msg":…} {"event":"progress","value":0…1} {"event":"log","line":…}
//   {"event":"result","data":{…,"outputs":[пути]}} {"event":"error","msg":…}; stderr → log.txt.
// stop: SIGTERM группе, через 3 с SIGKILL; код ≠ 0 без события result → Failed «Exit code N».
```
