# Clone'n'Speak 2.0 — подплан A: перекраска существующих страниц (Task 5 мастер-плана)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Каждая существующая страница (Речь, Голоса, Модели, Настройки, Лог, Установка, лист обучения) выглядит как Applio в обеих темах и во всех 8 палитрах: пронумерованные карточки, «Дополнительно» в раскрывающемся блоке, `OVSegmented`, SF Symbols, ghost-кнопки, `OVDropZone`, пустые состояния — и помещается в экран 1280×720 pt.

**Architecture:** Задача 5.0 (одна, первая) добавляет общие помощники только в `OVDesign`/`OVUI` (+ мелкие переключатели снимков). Затем шесть задач — по одному файлу страницы, параллельно, без пересечений. Последняя задача — сквозная сверка (палитры, малый экран, перекраска на лету). Поведение страниц не меняется: те же селекторы, ключи `NSUserDefaults`, уведомления; меняется только раскладка и вид.

**Tech Stack:** Objective-C/AppKit, `OVTheme`/`OVDesign`/`OVUI` из Tasks 1–2, реестр страниц из Task 3 (id: `synth, voices, models, settings, setup, log`, + `gallery`).

**Spec:** `docs/superpowers/specs/2026-11-09-clonenspeak-2.0-design.md` (разделы «Дизайн-система», «Страница Речь», «Установка», «Улучшение всего приложения»). Референсы: `docs/superpowers/specs/applio-refs/{tts,tts-bottom,models,settings,setup}.png`. Текущий вид: `/tmp/cns-snap-{dark,light}/*.png`, `docs/screenshots/*.png`.

## Global Constraints

Всё из «Global Constraints» мастер-плана (`2026-11-09-clonenspeak-2.0.md`) плюс:

- Сторонние цвета запрещены: только `OVColor(OVRole…)` или `OVColorAlpha(role, a)`. Никаких `NSColor.secondaryLabelColor/tertiaryLabelColor/systemOrange/systemRed/systemBlue`, `OVAccent()`, `OVGreen()`, `.CGColor`, `colorWithAlphaComponent:` в страницах. Соответствие: `labelColor→OVRoleText`, `secondary/tertiary→OVRoleMuted`, `systemOrange→OVRoleWarn`, `systemRed→OVRoleErr`, `OVGreen→OVRoleOK`, `OVAccent→OVRoleAccent`.
- Рамки/заливки — только через `OVBoxView`/`OVCard`/`OVBadge` (цвет берётся при отрисовке), не через `layer.borderColor`. Так перекраска палитры на лету работает без перезапуска.
- Эмодзи в интерфейсе — ни одного (включая `✨`, `✓`, `⚡️`, `📖` в строках `L(@"…")`; `✓ Installed` → `OVBadge`). Иконка без текста обязана иметь `accessibilityLabel` + `toolTip`.
- Размеры (pt): отступы страницы 24 сверху, 28 по бокам, 28 снизу; промежуток между карточками 16; padding карточки 20; внутри карточки между блоками 16; метка поля → контрол 8; контрол → подсказка 6. Метка поля 14/semibold, подсказка 13 `OVRoleMuted`. Высота поля/попапа 36. Кнопки 36 (CTA/ghost), иконочные 28, play 32.
- Экран пользователя 1280×720 pt: окно не выше `visibleFrame − 16` (уже в `main.m`), минимальное окно 820×560 → ширина контента ≥ 590. Каждая страница — `OVPageScroll` (прокручивается), ни одна не держит фиксированной высоты больше окна; двухколоночные ряды делят ширину поровну, колонка ≥ 260. Исключения: Голоса (список слева + прокрутка справа) и Лог (лог занимает высоту, `min 200`).
- Каждая задача добавляет русские строки **только** в свой фрагмент `Resources/ru.lproj/fragments/pages-<имя>.strings` (общий `Localizable.strings` не трогать — параллельные ветки конфликтуют); `python3 tools/strings.py merge` выполняет только 5.7.
- Коммиты — в ветку `release/2.0`, по одному на задачу, английские сообщения + трейлер соавтора, как в остальных коммитах сессии.

## Review Focus

1. **Палитра на лету**: смена палитры/темы при открытой странице (Речь с историей, Модели со строками, Установка в процессе) оставляет старые цвета (рамки, бейджи, значки, `meta`). Тест: 5.7 — `tools/snapdiff.py` сравнивает снимок после `OVTheme setPaletteId:@"sunset"` в работающем приложении с холодным стартом `-OVPalette sunset` для каждой страницы (расхождение ≤ 0.1 % пикселей).
2. **Малый экран**: 1280×720 pt (окно ≈ 1264×680) и минимальное 820×560 — главное действие страницы (Speak, Clone voice, Get started, Train) достижимо прокруткой, ничего не обрезано и не наезжает. Тест: снимки с `OV_SNAPSHOT_SIZE=1264x660` и `820x540`, у каждой страницы просмотрен последний экран `<page>-N.png`.
3. **Длинное и пустое**: имя голоса 80 символов; русские строки длиннее английских на 30 %; текст 8000 знаков; 0 голосов; 0 записей в истории; 50 записей; 0 моделей в каталоге. Ожидание — усечение с `…` и tooltip, без перекрытий, пустое состояние вместо пустой рамки. Тест: ручной прогон на «грязных» данных в задаче каждой страницы (список в её шаге Verify).
4. **Клавиатура и VoiceOver**: иконочный `OVSegmented` настроений (8 сегментов без текста), `OVDisclosure`, плитки палитр, шаги установки. Ожидание — Tab проходит по всем контролам, ←/→ в сегментах и плитках, VoiceOver читает «Calm, radio button, 2 of 8», «Step 2, Speech synthesis model, Ready». Тест: `OVGalleryA11yDump`-подобный дамп дерева доступности страницы (задача 5.0 добавляет `-OVA11yDump YES`), проверка в 5.7.
5. **Reduce Motion / Increase Contrast**: раскрытие блоков и индикатор неопределённого прогресса без анимации; рамки карточек при Increase Contrast не слабее 3:1. Тест: 5.7 — включить оба в Системных настройках, снимки Setup (идёт установка) и Speech.
