# Clone'n'Speak 2.0 — подплан C: pro-движки (Task 7 мастер-плана)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Все PyTorch-функции 2.0 работают на этом Mac (M4, 16 ГБ): менеджер движков (установка/удаление/статус/размер), Convert (RVC + Seed-VC), Realtime, Training, Voice Blender, RVC-модели на странице Models, полное Separation, Edge TTS на странице Speech, YouTube-импорт. Каждая функция — `OVProBadge` + `OVConfirmProRun`; OmniVoice выгружается до любой pro-задачи; два pro-движка одновременно не живут. Ничего не вырезается («Без отсева»); единственное условное место — смешивание OmniVoice-голосов (спека: «только если звучит») и веса разделения без проверенной лицензии (заменяются, см. 7.5).

**Architecture:** Движки — отдельные процессы Python. Приложение (ObjC) ничего не знает про torch: `OVEngines` читает статус у `cns_engines.py` (stdlib, основной runtime), ставит/удаляет по кнопке, а работа идёт через `OVJobs` из подплана D (`registerKind:` + `OVProcessRunnerFactory`; JSON-строки stdout как у `worker.py`). Один скрипт — один пакет команд: `python <script>.py <command>`, запрос JSON в stdin, события `status/progress/log/result/error` в stdout. **Одно общее pro-окружение** (Python 3.11, torch 2.8.0 — набор, проверенный спайком) вместо трёх; при невозможности ослабить пины — fallback «два окружения» (7.1, `layout: split`). Реалтайм — исключение: аудио идёт по Unix-сокету, микрофон держит приложение (AVAudioEngine), TCC остаётся за ним.

**Tech Stack:** Objective-C/AppKit, AVAudioEngine/CoreAudio, Python 3.11 (pro-окружение: torch 2.8.0 + MPS, numpy 2.4.6, librosa 0.11, transformers 4.46.3, audio-separator 0.45.0, faiss-cpu, torchcrepe, torchfcpe, onnxruntime, sounddevice, webrtcvad-wheels, tensorboard), `edge-tts==7.3.1` (LGPL, отдельный процесс), `yt-dlp` (свежий), `uv 0.13`, Applio `59c113106c0dfff647324ab1a80c286f17b51929` (MIT), Seed-VC `51383efd…` (GPL-3, как в 1.0.3).

**Spec / факты:** `docs/superpowers/specs/2026-11-09-clonenspeak-2.0-design.md`; спайк `docs/superpowers/notes/2026-11-09-pro-engines-spike.md` (лежит в ветке спайка `agent-a0377a62a8158d3d3`; **предусловие плана: она влита в `release/2.0`**, вместе с `tools/spikes/*`). Все числа ниже — оттуда.

## Global Constraints

Всё из «Global Constraints» мастер-плана, подплана A (только `OVColor/OVColorAlpha`, без эмодзи, отступы, строки `L(@"…")` только в свой фрагмент `Resources/ru.lproj/fragments/pro-<имя>.strings`; `tools/strings.py merge` не запускать — его запускают 5.7/8.10/7.16) и подплана D (всё сетевое — через `OVNetwork`/`cns_net.require_online`; секреты не в логах и `job.json`), плюс:

- **Интерфейсы D потребляем, не переопределяем:** `OVJobs registerKind:lane:retryable:title:factory:onSuccess:`, `OVProcessSpec` (`executable/arguments/environment` — ровно это/`currentDirectory`/`stdinData`/`beforeStart`), `OVProcessRunnerFactory`, `OVJobContext` (`workDirectory`, `registerPartialPath:`), `OVNetwork requestFeature:window:completion:` (`OVNetEdgeTTS`, `OVNetYouTube`, `OVNetModelDownload`), `cns_net.require_online`. Новых очередей и логов нет. Все pro-виды — `OVJobLaneCompute` (это и есть «два pro-движка не одновременно»; реалтайм держит lane, пока идёт сессия). Установки/загрузки весов — `OVJobLaneNetwork`.
- **Окружение процессов — только словарь** (`OVProcessSpec.environment` без наследования): `PATH=/usr/bin:/bin:/opt/homebrew/bin:/usr/local/bin` (ffmpeg), `HOME`, `TMPDIR=<work>`, `LANG`, `PYTHONNOUSERSITE=1`, `PYTHONDONTWRITEBYTECODE=1`, `PYTORCH_ENABLE_MPS_FALLBACK=1`, `OV_OFFLINE`, `HF_HUB_OFFLINE=1` (кроме установки). Токен HF/ключ API — никогда.
- **Чужие `.pth` — это pickle.** Импорт и осмотр модели из интернета: только `torch.load(weights_only=True)` в процессе без сети (`sandbox-exec`, профиль `cns_engines.sandbox_profile(deny_network, write_roots)`); если загрузка не проходит — «This isn’t a safe voice model file», файл не принимается. `inspect_checkpoint`/`model_information` Applio с откатом на `weights_only=False` для чужих файлов не вызывать.
- **Код Applio/UVR/Seed-VC в репозиторий не копируется.** Ставится в рантайме; установщик проверяет sha256 **каждого** распакованного файла по `Sources/cns_pins.py` (генерирует `tools/pin_applio.py` из tarball и сверяет с `backend/revision.json` приложения Applio — там те же хэши). Несовпадение → установка падает, ничего не помечается готовым. Пути из архива: только `core.py`, `LICENSE`, `rvc/**`, `assets/config_template.json`; симлинки и `..` отвергаются.
- **Частичная установка никогда не «готова».** Готовность = файл `ready.json` (пишется последним, удаляется первым при любой переустановке) + `schema` совпадает + python на месте. Загрузки — в `*.part` с докачкой (`Range`) и sha256 до переименования.
- **Память:** до старта pro-задачи — `[OVWorker shutdown]` (убивает процесс с OmniVoice/Whisper), затем проверка свободной памяти по таблице пиков (`PEAK_GB` в `cns_engines.py`: infer 3.4, seedvc 4.0, train 10.0 / batch 2 — 8.2, realtime 2.7, mdx 6.5, roformer 6.6, blend 1.0, ytdlp/edge 0.3) × 1.15; не хватает — предупреждение с цифрами, обучение само предлагает batch 2. Mac < 16 ГБ — `OVConfirmProRun` (предупреждение, не запрет). Отказ пользователя **не** выгружает модели. Watchdog: обучение — нет `step=` 120 с; остальное — нет ни одного события 300 с → группа процессов убивается, ошибка «Stalled — probably low memory. Close other apps and retry».
- **Нет скрытой сети.** Pro-процессы (кроме установки/обновления/yt-dlp/Edge/явной загрузки модели) запускаются с `OV_OFFLINE=1` и под `sandbox-exec (deny network*)`. Проверка в 7.2 и 7.5: инференс и разделение проходят при запрещённой сети (Applio `prerequisites` и `download_checks.json` audio-separator не должны ходить в интернет).
- **Каждая pro-функция:** `OVProBadge()` в шапке, `OVConfirmProRun(window)` перед запуском, карточка-шлюз `OVEngineGateCard` вместо контролов, пока компонент не `Ready`.
- Коммит на задачу, в `release/2.0`, английское сообщение + трейлер соавтора.
