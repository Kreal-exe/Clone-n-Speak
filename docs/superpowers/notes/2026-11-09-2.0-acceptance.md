# Clone'n'Speak 2.0: acceptance notes (integration run, 2026-11-19)

Machine: Mac mini M4, 16 GB, macOS 15. Build: `CI=1 INSTALL_DIR=/tmp/cns-int-app ./build.sh` (never installed into
/Applications). Runs used scratch folders under `/tmp/cns-int-run` and a throw-away data folder (`OV_DATA_DIR`) plus a
snapshot build with its own bundle id, so the app's real settings and data were not written. All audio used here is
generated speech (`say`) mixed with synthetic music; no user recordings, voices or texts.

## Model folder (item 13)

Settings > Storage > "Model folder" shows the folder, its free space, a warning when the folder lives on a volume that
is not connected ("The model folder is on 980PRO, which isn't connected — connect it or choose another folder"), and
Choose... / Default folder / Show in Finder. The choice is the existing `hfCacheDir` default; it now goes through
`OVModels setHubCacheOverride:` (stops the engine so it restarts with the new `HF_HUB_CACHE`, rescans). The worker gets
`HF_HUB_CACHE`; model detection, downloads, Setup and Models texts use the same folder; Setup and Models also show the
warning. Pro engines keep their own pinned weights and run offline, so they do not read this folder (Seed-VC has its own
`hf` cache by design); say so if that should change.

## Not done / limits

- `OVProKit` gate fix, Training sheet, accent and history changes have no automated UI test; they were built and, where
  a snapshot can show them, looked at.
- DFN strengths 6/18/30 dB, "remove music", sample check, QuickTime opening of the six formats, presets round trip,
  batch with stop, the 30-minute file error, LoRA by link and the player scrubber/A-B were covered by the unit tests of
  tasks 6.x (all pass) but not re-done by ear or by hand here.
- The "clean install" scenario (delete `engines/` and `rvc/`, install about 1.9 GB) and the 8 GB-equivalent scenario
  (`ps` shows no `worker.py` during a pro job) were not run: they would delete or reload the user's real engines.
- One mistake to report: while taking the Tools snapshot I symlinked the real `runtime/` folder into a scratch data
  folder, and the snapshot build copied three engine scripts (`cns_ytdl.py`, `cns_net.py`, `cns_train.py`) into the real
  runtime folder. They are the versions of this branch. The installed 1.0.3 app copies its own scripts over them on its
  next launch. Nothing else in the real data was written; later runs used copies (`cp -c`).

## For the user

1. Realtime with a microphone: run `tools/rt_latency_check.py` (and `tools/rt_client_check.py`) with a real input and
   output device, then open Realtime, choose a voice model, Start, speak, check the latency number and that Stop ends
   cleanly. Use headphones (feedback guard).
2. Bridge: on the signed build switch Bridge on, let it download the tunnel program, pair a phone (the Mac asks to
   approve), run a job from the phone, revoke the device on the API page and check the phone gets 401. Then quit the
   app and `kill -9` it in a second run and check `ps aux | grep cloudflared` shows nothing left.
3. Edge TTS and YouTube import: each asks for consent once; try one sentence and one short video link, then switch on
   Offline mode and check both are refused with the Offline text, and that a model download is refused too.
4. Keychain: with the signed build, enable the local API, check the Keychain prompt appears once, "Always allow" keeps it
   quiet after a relaunch, and the key never shows in `~/Library/Application Support/Clone'n'Speak/logs`.
5. Model folder on the external disk: Settings > Storage > Choose..., pick `/Volumes/980PRO/.cache/huggingface/hub`,
   check Setup and Models show it, eject the disk and check the warning and the refused download text, reconnect.
6. Listen: DeepFilterNet at 6/18/30 dB, formant and pitch, the 11 effects, RVC and Seed-VC output on a voice you know,
   the Russian and Ukrainian verdict notes from task 7.2.
7. Memory for the models not installed here: install the voice extractor and DeepFilterNet from Models, run `sep_vocals`
   on 30 s and `dfn_apply` and read the peaks from Activity Monitor; run "clone + 30 s of speech" and compare with 1.0.3.
8. Clean install and the 8 GB-equivalent scenario from task 7.16 (delete `engines/` and `rvc/` on a spare account first).
