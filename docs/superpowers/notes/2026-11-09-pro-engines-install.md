# Installing the pro engines (Task 7.1)

`Sources/cns_engines.py` is the only thing that installs RVC, Seed-VC, stems, Edge TTS and yt-dlp. Pins live in
`Sources/cns_pins.py`, generated by `tools/pin_applio.py` (needs the network; compares the Applio file hashes with the
desktop Applio's `backend/revision.json` and stops on any difference).

## Folder layout (`<root>` = the app's engines folder)

| Path | What |
|---|---|
| `pro/.venv`, `pro/ready.json` | the shared environment (Python 3.11, torch 2.8.0): Applio + Seed-VC + audio-separator + yt-dlp |
| `applio/` | `core.py`, `LICENSE`, `rvc/**`, `assets/config_template.json`, `requirements-engine.txt`; `applio/rvc/models` is a symlink to `../../weights`, `applio/logs` a symlink to `../training` |
| `weights/` | `predictors/`, `embedders/contentvec/`, `pretraineds/hifi-gan/` (the layout `prerequisites_download.py` uses); markers in `weights/.state/<id>/` |
| `training/` | trained voices and `mute/` (silent clips training mixes in, from the Applio tarball). Never removed by an update or by uninstall |
| `seedvc/seed-vc`, `seedvc/hf` | Seed-VC source and its Hugging Face cache (`HF_HOME` for every Seed-VC process: `seedvc_env(root)`) |
| `edge/.venv` | separate environment with `edge-tts==7.3.1` |
| `stems/<id>/` | stem models (Task 7.5 adds them to `cns_pins.STEMS`) |
| `engines.json` | optional `{"layout": "split"}` |

A component is ready only when its `ready.json` exists and what it promises is still on disk (python executable,
every weight at its pinned size, every extracted file at its recorded size). `ready.json` is removed first when an
install starts and written last; `installing.json` marks a started install. A killed install is `partial`, and the
next Install resumes: uv's cache, `.part` files with a `Range` request, the already-extracted pieces.

## The `split` fallback

If the relaxed pins of the shared environment ever cannot be kept (an Applio update needing `transformers 5` or
`numpy 2.4.6` together with Seed-VC's `transformers 4.46.3`), `engines.json` with `{"layout": "split"}` adds the
component `applio-env`: `applio`, `rvc-*` run in `applio-env/.venv` (torch 2.11.0, installed from the strict freeze
`APPLIO_STRICT_CONSTRAINTS` as both requirements and constraints), while `pro-env` (torch 2.8.0) serves Seed-VC and the
stems. `python_for(root, component)` answers which interpreter a component uses. The tests install both with a fake
`uv` (no torch); the strict freeze comes from a Python 3.12 spike run and has not been installed on 3.11: unverified.

## Not downloaded

Applio's own `prerequisites` fetch 1.9 GB (every sample rate, RefineGAN, swift.onnx). The manager downloads only the
pinned files: `rmvpe.pt`, `contentvec` (+`config.json`) for `rvc-core`, `fcpe.pt`, and one pair `f0G/f0D` per rate.

## Safety rules of the installer (fix round 1)

- **Environment.** Every child (uv, source builds, the Seed-VC run) gets an allowlist: fixed `PATH`, `HOME`, `TMPDIR`,
  `LANG`, `PYTHONNOUSERSITE=1`, `PYTHONDONTWRITEBYTECODE=1`, `UV_CACHE_DIR=<root>/.uv-cache`, plus the caller's explicit
  keys minus `UV_INDEX*`, `PIP_*`, `HF_TOKEN*` and anything named like a token, key, secret or password.
- **Wheels only.** All `uv pip install` calls use `--only-binary :all:`, with these documented exceptions (no usable
  wheel on PyPI for Python 3.11 / macOS arm64, 2026-11-09): `diffq` (stage 1; C extension required by audio-separator,
  built from its sdist, needs the Xcode Command Line Tools), `argbind` and `randomname` (stage 3; pure Python sdists).
- **Edge** installs into its own environment with a pinned freeze of `edge-tts` and its dependencies
  (`cns_pins.EDGE_CONSTRAINTS`); `edge-tts` is not part of the pro environment's requirements.
- **Seed-VC models are pinned.** The first run used to let Seed-VC fetch whatever it wanted. Now `cns_pins.SEEDVC_MODELS`
  lists repo, exact revision, files and sha256 for the four models the default path loads (Plachta/Seed-VC DiT +
  config, funasr/campplus, nvidia/bigvgan_v2_22khz_80band_256x, openai/whisper-small). They are downloaded with the
  resumable, size-capped, hash-checked path into Hugging Face cache layouts (`seedvc/hf/checkpoints`, what
  `load_custom_model_from_hf` reads through the `seed-vc/checkpoints` symlink, and `seedvc/hf/hub`), and the warm-up
  conversion runs with `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1` and a 15 minute timeout. Small non-LFS files
  (config.json, the yml) are trust-on-first-pin: their sha256 is computed when `tools/pin_applio.py` runs.
- **Sandbox.** `sandbox_profile` aims at "no network, no writes outside the roots". Reads and exec stay open, and the
  caller must list `TMPDIR` among the write roots.
