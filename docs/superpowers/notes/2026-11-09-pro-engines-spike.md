# Спайк pro-движков (M4, 16 ГБ, macOS 15) — 2026-11-09

Факты для подплана C (RVC, обучение, реалтайм, разделение, DeepFilterNet, edge-tts, yt-dlp). Всё измерено на этом Mac
(Mac mini M4, 16 ГБ) скриптами из `tools/spikes/`. «unverified» — установить из артефактов не удалось.

Условия измерений: тихий Mac (кроме одного эпизода, описанного ниже); тестовая речь — `say -v Samantha` (английский,
115 с для обучения, 10 с для инференса), «музыка» — синтез numpy; Python 3.12 для первых прогонов, итоговая проверка
общего окружения — на Python 3.11 (это версия runtime приложения). Окружения создавались только в
`~/Library/Application Support/Clone'n'Speak/engines-spike/` (удалено).

## Что осталось unverified

- Живой edge-tts и yt-dlp (хосты вне разрешённых для спайка).
- Задержка реального аудио-ввода/вывода (sounddevice, микрофон не использовался).
- Лицензии весов Kim_Vocal_2 и BS-Roformer у их авторов; Applio-претрейны унаследованы от `lj1995/VoiceConversionWebUI` (MIT).
- Качество обученного 2 эпохи голоса не оценивалось (проверена только работоспособность `.pth`/`.index`).
- Русский/украинский вход для RVC и Seed-VC не проверялся (тест на английском; contentvec — английский эмбеддер,
  для других языков у Applio есть `chinese-/japanese-/korean-hubert-base`, ru/uk — не проверено).

## Воспроизведение

Скрипты: `tools/spikes/gen_audio.py` (тестовое аудио), `infer_bench.py`, `rt_bench.py` (замер цепочки реалтайма),
`ort_vocals.py` (MDX через onnxruntime), `sisdr.py`, `memwatch.py` (peak памяти дочерних процессов по `top`; `time -l`
показывает только родителя). Окружения: `pro-env-py311-requirements.txt` + `pro-env-py311-freeze.txt` (рабочее общее),
`applio-strict-py312-freeze.txt` (точные пины Applio).
